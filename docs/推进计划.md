## 0. 基线（已完成）

CubeMX 初始化已冻结并通过编译验证（Flash 13488B / RAM 3080B），无需再改：

| 定时器 | 频率 | 职责 |
|---|---|---|
| TIM1 | 1kHz（1ms 字符槽） | 槽切换：关阴极 → 关 PMOS → 换字符 → 清 TIM2 计数 |
| TIM2 | 20kHz（50µs × 20 tick/槽） | 阴极软件 PWM：20 级亮度 |
| TIM3 | 100Hz（10ms） | 应用节拍 + TRGO 触发 ADC |

NVIC：TIM1_UP = TIM2 = 0（同级）、TIM3 = 1、DMA = 2、USART1 = 3、SysTick = 15
ADC1：CH0(PA0) = 电源键电压、CH1(PA1) = 电位器；USART1 115200 + DMA 发送。

## 1. 三条硬件约束（决定了能做什么）

| # | 约束 | 结论 |
|---|---|---|
| 1 | **亮度只能按"字符"调，不能按"点"调** | PWM 做在共用的 K 通道上，一个槽只有一个字符导通。所以数据是 `mask[4] + duty[4]` |
| 2 | **一条通道的电流预算 ≈ 11.7mA** | `(3.3−2.1−0.03)/100Ω`。4 颗灯共用这一份。全部模式统一走 4 槽扫描 |
| 3 | **最亮时单灯平均约 2.6mA，可能偏暗** | 不够亮就把限流电阻 100Ω → **68Ω**（峰值 17.1mA，仍在 20mA 额定内，亮度 +47%） |

**扫描为什么反而更好**：它让每颗灯在自己的槽里**独占** 11.7mA → 32 颗亮度完全一致；常亮时 4 颗灯并联会按 Vf 抢电流，亮度差可达 3 倍。

## 2. 模式总表

### 2.1 五个模式（MODE5 同时兼作开机动画）

| 编号 | 名称 | 显示效果 |
|---|---|---|
| **MODE1** | 累计书写 + 逆序擦除 | 一条"笔尖"沿 32 个点前进，走过的地方**累积点亮**（笔尖处约 120ms **渐亮**）→ 全亮保持 0.3s → 笔尖回到起点**按原顺序再扫一遍，被扫过的点渐灭** → 全灭保持 0.2s → 循环 |
| **MODE2** | 字符流水 | 一个字母的 8 灯**全亮** → 保持一段时间 → 下一个字母全亮 → 循环 |
| **MODE3** | 同步呼吸 | 32 颗灯权重全满，四个字母的整体亮度**同步**做 0 → 峰值 → 0（升余弦再取平方的包络，64 个相位，gamma≈2 让感知亮度接近正弦），一轮约 3.8s |
| **MODE4** | 流水 + 呼吸 | 只有**当前字母**的 8 灯参与呼吸（用和 MODE3 同一条包络），一个字母完成一次呼吸（暗→亮→暗）后换下一个；**换字母发生在 duty=0 的全黑瞬间，看不见接缝**。每个字母约 2.1s，四个字母一轮约 8.4s |
| **MODE5** | 描边游走 | 一个**平滑彗尾**（每点 8 级亮度权重：头部前方 1 点渐亮、后方 3 点渐灭，亮度分布连续滑动）沿笔画路径滑过 B→N→G→U 共 32 点 → 四字母**整体渐亮 0.38s** → **全亮保持 0.7s** → **整体渐灭 0.38s** → 全灭保持 0.3s → 循环，一轮约 5.8s |

**MODE5 同时是开机动画**：上电后先跑**一轮** MODE5（兼焊接/接线核对：哪颗灯不亮、哪路 MOSFET 没接好一眼就能定位）→ **全黑待机，按任意键才开始 MODE1**。

**开机动画的走速固定 120ms/点、亮度固定满档，不受电位器和 KEY3 影响** —— 自检必须每次都一样、而且一定要看得见。只有手动用 KEY2 选到 MODE5 时，走速和亮度才跟电位器。

**KEY2 的循环顺序**：MODE1 → MODE2 → MODE3 → MODE4 → MODE5 → MODE1。

### 2.2 按键与电位器（全局统一）

| 输入 | 功能 |
|---|---|
| **任意键**（待机时） | 退出黑屏待机，开始 MODE1 |
| **KEY2**（短按） | 循环切换模式：MODE1 → MODE2 → MODE5 → MODE1。**切换时全屏快闪 N 次**提示模式号（MODE1 闪 1 下、MODE2 闪 2 下、MODE5 闪 5 下，因为板子上没有屏幕） |
| **KEY3**（短按） | 切换电位器控制的对象，三档循环：<br>**③ 联动（默认）** → 电位器同时按比例调亮度和速度<br>**① 亮度峰值** → 电位器只调最亮档，速度保持不动<br>**② 速度** → 电位器只调动画快慢，亮度保持不动 |
| **电位器**（ADC2 / PA1） | 按 KEY3 当前档位调节。**软接管**：切档位 / 切模式 / 上电时的参数先冻结，等电位器真的转过 5% 才重新跟手 —— 所以任何一步都不会有亮度或速度突跳 |
| **电源键 + ADC1**（PA0） | 长按 300ms 关机（Phase E 实现） |
| **KEY1**（PB11） | 上电自锁（CubeMX 初值已是高电平）；关机时拉低切断电源（Phase E 实现） |

### 2.3 各模式里"速度"和"亮度峰值"具体指什么

| 模式 | "速度" = 电位器在调什么 | "亮度峰值" = 电位器在调什么 |
|---|---|---|
| MODE1 | 每点亮/熄灭**一个点**的时间间隔 | 点亮时用的 duty 上限（4~19 级） |
| MODE2 | 每个**字母**的保持时间 | 同上 |
| MODE3 | **一次完整呼吸**（亮→暗→亮）的时长 | **呼吸的最亮档**（4~19 级） |
| MODE4 | 每个字母**一次呼吸**的时长 | 同上 |
| MODE5 | 每走**一个点**的时间间隔 | 同上 |

**默认值（上电冻结点）**：亮度 **19/19**、速度 **12 tick（120ms/点）**，与开机动画完全一致，进入 MODE1 时不会跳变；KEY3 为③联动。

## 3. 关键机制（编码时必须做对）

| # | 机制 | 做法 |
|---|---|---|
| 1 | **回调必须按 Instance 分派** | `HAL_TIM_PeriodElapsedCallback` 里判断 `htim->Instance`，否则 TIM1/TIM3 会去跑 PWM 代码 → 亮度乱跳（现象极像硬件故障） |
| 2 | **槽切换四步顺序 + 消隐** | TIM1 中断：①阴极全拉低 ②4 个 PMOS 全关 ③切字符 ④`TIM2->CNT=0` + 清 UPDATE 标志。掩码写入与 PMOS 开启推迟到 TIM2 第 `BLANK_TICKS` 个 tick |
| 3 | **消隐 tick 数** | `BLANK_TICKS` 从 **1（50µs）** 开始；47k 上拉下 Vgs 已降到 -0.56V（低于 -0.9V 阈值），一般看不到鬼影。有残影就升到 2 |
| 4 | **相位锁定** | 每个槽起点清零 `TIM2->CNT`，否则每槽最后一个 tick 被截断，最高亮度掉到 19/20 |
| 5 | **每点亮度 = 槽内子时段（8 级权重）** | PWM 在共用阴极上做不到分点调光。所以把 1ms 槽再切成 `WEIGHT_LEVELS`(=8) 个子时段，权重 w 的点在前 w 个子时段点亮 → 同一字符内也有 8 级明暗。子时段掩码由权重自动推导（`led_matrix_publish`），效果层只填权重。全局亮度仍由 `duty` 控制，两者相乘 |
| 6 | **ISR 只置标志位** | 不做 `HAL_Delay`/串口/printf。效果逻辑放主循环，方便断点调试不打断 PWM |
| 7 | **数据跨中断** | `mask[]`/`duty[]` 是单字节写入（天然原子）；如需整组一致，用 <1µs 的短临界区 |
| 8 | **串口用整数 mV** | 链接用 nano.specs 且未开 `_printf_float`，`printf("%f")` 会静默输出空。用 `HAL_UART_Transmit_DMA` + 忙标志（忙就丢帧，不阻塞） |

## 4. 串口遥测（Phase A 就写好）

**速率 10Hz**，DMA 发送，格式：

```
[BOOT] BNGU Light v1.0  selftest start
[KEY ] KEY2 -> MODE=3
[KEY ] KEY3 -> POT=SPEED
[TLM ] MODE=2 BRIGHT=15/18 SPEED=30 ADC1=12mV ADC2=1650mV
```

| 字段 | 含义 |
|---|---|
| MODE | 当前模式号（自检期间显示 0） |
| BRIGHT | 当前亮度峰值 / 18 |
| SPEED | 当前速度档 |
| ADC1 | 电源键检测电压（mV）——不按键应接近 0，按下约 2500 |
| ADC2 | 电位器电压（mV） |

## 5. 分阶段推进

### Phase A —— 扫描引擎 + 自检程序 + 串口
**做什么**
1. 扫描引擎：4 槽 × 1ms、20 级 PWM、消隐、相位锁定、按 Instance 分派的回调
2. 32 点路径表（按笔画顺序编号）
3. **自检程序**：平滑彗尾描边游走（**120ms/点**；每个点 **8 级亮度权重**，头部前 1 点渐亮、后 3 点渐灭，亮度分布连续滑动而不是逐格跳；**每个字符一张 K 重排表**，N 的 6/8 号已互换）→ 32 点走完（约 4.1s）→ 整体渐亮 0.38s → 全亮 0.7s → 整体渐灭 0.38s → 全灭 0.3s → 循环
4. **串口遥测 + ADC 采集（只读）**：这一阶段只把 ADC1/ADC2 的值读出来发出去，先不参与控制（控制从 Phase B 开始）

**验收**
- 32 灯全亮、无鬼影、20 级亮度肉眼可分
- 描边游走能逐点走完 B/N/G/U，彗尾看得见
- 串口每秒稳定收到 10 帧；**ADC2 随电位器旋动而变化**（这一条同时证明 TIM3 的 TRGO 触发链正常）；ADC1 不按键时接近 0mV
- 自检本身就是接线核对工具，不用另写测试程序

### Phase B —— MODE1 + MODE2 + 电位器 + KEY2/KEY3
**做什么**
1. MODE1 累计书写 + 逆序擦除
2. MODE2 字符流水
3. ADC2 参与控制（滤波 + 感知映射 + 死区）
4. KEY2 切模式（含闪 N 次提示）、KEY3 三档（亮度峰值 / 速度 / 联动）
5. 自检改为「上电跑一次 → 进入 MODE1」

**验收**
- KEY2 在四个模式间循环正确，闪灯提示与模式号一致
- KEY3 三档切换后，电位器分别只调亮度、只调速度、两者联动
- 串口里的 MODE / BRIGHT / SPEED 跟着按键和电位器实时变化

### Phase C —— MODE3 同步呼吸
**做什么**：`App/mode_breath.c` —— 32 个点权重全满，只调每个字符的整体亮度 duty，
四个字符用同一个值，所以是"同步呼吸"。包络是 64 相位的升余弦平方表（gamma≈2），
`duty = 包络 × 亮度峰值 / 255`，所以电位器直接缩放整条包络。
速度由一个相位持续 `g_speed / BREATH_SPEED_DIV` 个 tick 决定，默认一轮约 4.2s。

**验收**：呼吸连续无跳变；变亮与熄灭时长对称；电位器两端差异明显（速度 0.64s ~ 16s 一轮，峰值 4~19 级）。
**已知限制**：`duty` 只有 20 级（TIM2 20kHz → 每 1ms 槽 20 个 tick），
最低点 duty 0↔1 在感知上是 0↔38% 的跳变。若看着刺眼，把 TIM2 的 Period 从 49 改成 24
（20kHz → 40kHz，每槽 40 个 tick，38 级、BLANK_TICKS 同时改成 2 保持 50µs 消隐），
跳变幅度能降到 29%，代价是 TIM2 中断负载翻倍。

### Phase D —— MODE4 流水 + 呼吸
**做什么**：`App/mode_mix.c`，并把呼吸包络抽成 `App/breath.c` 给 MODE3/MODE4 共用。
只有当前字母的 8 个点权重满档、其余全灭，包络照常驱动整屏 duty —— 于是"这个字母在呼吸"。
换字母发生在相位绕回 0（duty = 0，全黑）的那一刻，所以看不见接缝。
每个字母约 2.1s（比 MODE3 快一倍，否则 4 个字母轮流一轮要 17 秒，演示太拖）。

**验收**：字母之间交接无跳变；KEY3 切换后速度/亮度峰值分别可调。

### Phase E —— 电源开关 + ADC1 + KEY1
**做什么**
1. ADC1 阈值实测标定（不按键 mV / 按下 mV）
2. 电源状态机：**上电先等按键释放**（带 5s 超时保护，避免按键卡死永远起不来）→ 武装关机检测 → **长按 300ms 关机**
3. 关机时序（顺序不可颠倒）：停 TIM → 12 个栅极置安全态 → 未用 IO 设模拟输入 → KEY1 拉低 → 死循环
4. 关机静态电流实测（题目进阶要求 <1mA）

**验收**：按住开关上电后松手不掉电；长按 300ms 关机；关机瞬间无闪灯；静态电流达标。

### Phase F —— 整合收尾
**做什么**：全功能联调、手感优化（如需要则把 100Ω 改 68Ω）、设计说明书软件章节、测试记录表、10~30s 视频分镜脚本。
**验收**：一次开机即可完整演示基础 + 进阶功能。

## 6. 风险清单（软件侧）

| # | 风险 | 症状 | 对策 |
|---|---|---|---|
| R1 | 整体偏暗 | 室内看不清 | Phase A 就判定；100Ω → 68Ω |
| R2 | PMOS 关断拖尾 | 字符残影 | `BLANK_TICKS` 1 → 2 |
| R3 | 回调未分派 | 亮度乱跳、槽错乱 | 见 3.1（最先写对） |
| R4 | 槽内 tick 数不为整数 | 亮度不均 | `TIM2->CNT` 清零 + 保持 1000/(Period+1) 为整数 |
| R5 | `printf("%f")` | 遥测电压字段为空 | 用整数 mV |
| R6 | UART DMA 重入 | 帧粘连 | 忙标志 + 丢帧 |
| R7 | 上电未等按键释放 | 设备起不来 | 释放检测 + 5s 超时 |
| R8 | 关机前未置安全态 | 关机瞬间闪灯 | 关机时序固定 4 步 |
| R9 | 电位器 ADC=0 映射全黑 | 误判为故障 | 死区 + 映射到 1~18 |
| R10 | 模式切换残留状态 | 新模式开头一帧花屏 | 每个模式带 `init()` 复位 |
